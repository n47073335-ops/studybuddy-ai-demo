Cách bật LLM thật

Khóa API chỉ lưu trên máy chủ, không nhập vào giao diện web.

  1. Tải và cài Python 3.10 trở lên.
  2. Chạy run_demo.bat trên Windows.
  3. Tạo khóa Gemini API trong Google AI Studio.
  4. Sao chép .env.example thành .env; đặt GEMINI_API_KEY=....
  5. Khởi động lại máy chủ rồi bấm “Kiểm tra kết nối backend”.
Không chia sẻ khóa API với người khác và không đưa tệp .env lên GitHub. Bản demo dùng API bên ngoài có thể chịu giới hạn hoặc chi phí tùy tài khoản/dịch vụ.
